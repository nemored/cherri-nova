# Changelog

## 0.1.3

- Improved syntax highlighting by using Nova-friendly scopes for functions, variables, constants, types, numbers, and processing directives.
- Added single-quoted string highlighting.
- Improved pragma matching for `#include`, `#define`, `#import`, and `#question`.

## 0.1.0

- Initial Nova extension release.
- Added syntax highlighting for `.cherri` files.
- Added Nova Extension Library metadata, icon, changelog, and license text.
